# Tahap 11 — Abstrak

## Tujuan
Abstrak 150–250 kata (atau ikut template Tahap 0), tanpa sitasi, tanpa klaim di luar badan.

## Prompt siap tempel

> Hai AI, sekarang saya minta Anda untuk menyusun Abstrak artikel ilmiah ini dalam Bahasa Indonesia, lengkap dalam satu kali generate, 150–250 kata, SATU paragraf (atau mengikuti template jurnal target bila saya sebutkan), tanpa sitasi dan tanpa singkatan yang tidak didefinisikan. Struktur: (1) latar/urgensi 1–2 kalimat; (2) tujuan 1 kalimat; (3) metode 2–3 kalimat (desain, data, analisis dari Tahap 2); (4) hasil utama 2–3 kalimat (angka/tema kunci saja); (5) kesimpulan/implikasi 1–2 kalimat. Gunakan past tense untuk metode/hasil ("we found...") dan present tense untuk kesimpulan ("this suggests..."). Akhiri dengan baris "Kata kunci: ..." berisi 3–5 kata kunci yang sama dengan Tahap 2. Jangan memasukkan klaim yang tidak ada di badan artikel.

## Gate
Kata sesuai template Tahap 0 + 5 unsur terisi + nol sitasi + nol klaim baru + kata kunci = Tahap 2.

## Tanya ke user
Template Tahap 0 minta abstrak terstruktur atau satu paragraf? Batas kata pastinya?

## Jebakan
Menyalin kalimat Kesimpulan persis → tulis ulang dengan redaksi berbeda.
