# Tahap 0 — Kunci Jurnal Target dan Template

## Tujuan
Jurnal + author guidelines dikunci SEBELUM generate isi apa pun. Template jurnal mengikat Tahap 1–13.

## Prompt siap tempel

> Hai AI, sebelum menyusun artikel ilmiah ini, saya akan menetapkan jurnal target publikasinya. Anda wajib mencatat dan mengunci informasi berikut sebagai template mengikat untuk seluruh tahap penulisan: (1) nama jurnal dan penerbitnya; (2) author guidelines resmi — batas kata naskah, struktur abstrak (terstruktur atau tidak), gaya sitasi, format tabel/gambar, ketentuan jumlah penulis, serta file template bila saya lampirkan; (3) scope jurnal dan alasan kecocokan topik penelitian saya. Seluruh bagian yang Anda hasilkan setelah ini harus menyesuaikan template tersebut, termasuk panjang abstrak (Tahap 11), struktur bab (Tahap 3), dan format sitasi (Tahap 1). Apabila ada konflik antara aturan Tahap 1 dengan template jurnal, template jurnal menjadi prioritas dan Anda wajib memberi tahu saya konfliknya secara eksplisit. Apabila saya belum menentukan jurnal target, JANGAN berasumsi: tanyakan scope penelitian, indeksasi yang diincar (SINTA/Scopus/Web of Science), kesediaan biaya APC, dan batas waktu saya, lalu usulkan 3 kandidat jurnal beserta alasan kecocokan masing-masing.

## Gate
Template tercatat (nama jurnal + batas kata + format abstrak + gaya sitasi) ATAU 3 kandidat jurnal sudah diusulkan dan user memilih satu. Bila gaya sitasi IEEE/Vancouver → aktifkan `references/format-ieee.md` dan nyatakan di Tahap 1.

## Tanya ke user
Sudah ada jurnal target? Jika ya: minta nama jurnal + guidelines/template-nya. Jika belum: scope, indeksasi incaran, APC, deadline.

## Jebakan
"Jurnalnya nanti saja, tulis dulu" → tolak; template menentukan bentuk semua bab.
